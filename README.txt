KIKERS 2.0 — сайт-шаблон
========================

Содержимое:
- index.html — готовая адаптивная одностраничная страница
- assets/kikers-plugin.png — скриншот интерфейса плагина

Как посмотреть:
1. Распакуйте архив.
2. Откройте index.html в браузере.

Как опубликовать:
Загрузите index.html и папку assets целиком на любой статический хостинг
(например, GitHub Pages, Netlify или ваш веб-хостинг).

Кнопки скачивания ведут на указанную ссылку Mail.ru Cloud.
Сайт не использует внешние библиотеки или сборку.
